## 7. Discoveries — six transferable tool-behavior findings

1. **TB-03** template scaffolds fix layout but defective anchors dominate content — never anchor repairs on non-conforming references.
2. **TB-04** per-cell capitalized names leak into images as rendered text — describe panels positionally + global no-words rule.
3. **TB-05** stale git tracking refs mislead — verify with `git ls-remote`; re-verify declared pre-staged files.
4. **TB-06** per-panel exact-count anchors multiply (radial anatomy *and* glyph ladders) — front-load exact counts; never identically retry a failed count.
5. **TB-07** the model can abandon scaffold canvases (1376×768) — verify dimensions every time; disclose, don't silently accept.
6. **TB-08** the model's landscape canvas ceiling: **14/14 landscape-class generations landed at exactly 1264×848** while squares were honored 10/10 — 3072×2048-class targets are unreachable in this environment; documented and owner-accepted.
